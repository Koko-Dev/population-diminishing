# 📚 SEO-Checklist.md

## 🌟 Core SEO Setup (For Every Site)

- [x] Set a clear and meaningful `<title>` tag for every page
- [x] Write a strong `<meta name="description">` that invites clicks
- [x] Use one (and only one) `<h1>` heading per page
- [x] Open your site to crawling in `robots.txt`
- [x] Provide a `sitemap.xml` for Google and Bing
- [x] Set up Open Graph and Twitter meta tags for beautiful social sharing
- [x] Ensure mobile-friendly responsive design
- [x] Serve site securely over HTTPS

---

## 🌟 Per-Page SEO Checklist

### 1. Titles
- [ ] Keep titles under 60 characters
- [ ] Make titles human, emotional, natural
- [ ] Include main keyword or theme naturally

### 2. Descriptions
- [ ] Write inviting descriptions between 140–155 characters
- [ ] Summarize what the reader will find
- [ ] Make descriptions encourage curiosity and trust

### 3. Headings
- [ ] Use one `<h1>` per page (main topic)
- [ ] Use `<h2>`, `<h3>` for logical sections if the page is longer
- [ ] Avoid skipping heading levels (example: don't jump from `<h1>` to `<h3>`)

### 4. Content
- [ ] Keep paragraphs short (3-4 lines)
- [ ] Use bullet lists where appropriate
- [ ] Link to other internal pages if you have them

### 5. Images
- [ ] Add `alt` text that clearly describes the image
- [ ] Keep file names clean and descriptive (example: `population-graph.png`)

### 6. Accessibility
- [ ] Ensure color contrasts are readable
- [ ] Provide text alternatives for visual content

---

## 🌟 After Launch

- [ ] Submit sitemap to Google Search Console
- [ ] Verify mobile usability in Search Console
- [ ] Monitor site coverage (errors, warnings)
- [ ] Track performance (clicks, impressions) over time

---

# 🌱 Notes for Future Growth

- As you add more articles or pages:
    - Give each new page a unique title and description
    - Use clean and logical URL structures (example: `/articles/population-crisis.html`)
    - Update your sitemap.xml if needed

- Later you can explore advanced topics:
    - Structured data / schema markup
    - Rich results (FAQs, breadcrumbs)
    - Building backlinks carefully (off-page SEO)
